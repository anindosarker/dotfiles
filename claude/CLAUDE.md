## Working style (all projects)

- DISCUSS FIRST. No Edit/Write until explicit "go / apply / yes".
- DO NOT ASK UNNECESSARY QUESTIONS. Trivial choices: decide yourself, do not ask.
- Delegate coding to agents; main session plans and reviews.
- Browser checks: Broswer-use/ Playwright / agent-browser. Use whatever appropriate. Default Browser-use.
- No em dashes.
- "Explain" always means explain simply: 3 to 4 short bullets, plain words without technical prose; detail only on a follow-up.
- AWLAYS reply with simple bullet points. Additional Text only when necessary
- For mockups, use excalidraw diagrams as default. Other formats when asked.

  - When using excalidraw diagrams, try to group items so its easier for me to quickly edit.
- Keep plans and discussion artifacts in the repo by default. General Format:

  - .ai/plans/[feature]/[git_username]/ : plan folder root.
    - /reference : for storing items like mockups, files etc.
