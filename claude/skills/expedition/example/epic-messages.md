# Epic message examples

Filled messages in the shapes of [../templates/epic-messages.md](../templates/epic-messages.md).

## Epic ready

```Markdown
**Epic ready: E12**
- D63: Sidebar menu scrolls above a fixed footer.
- D64: Billing is its own sidebar section with three pages.

**Say:**
- A. `compose`: plan.
- B. `compose delegate`: plan and start.
```

## Epic ready, with a blocked decision

```Markdown
**Epic ready: E12**
- D63: Sidebar menu scrolls above a fixed footer.
- D64: Billing is its own sidebar section with three pages.

**Blocked:**
- D65: Sidebar header shows the team name. Waits for E11, same file.

**Say:**
- A. `compose`: plan.
- B. `compose delegate`: plan and start.
- C. `compose delegate with D65`: the same, with D65 in it.
```
