# D58. The sidebar has a collapse shortcut

| System | Key |
|---|---|
| macOS | `Cmd+B` |
| every other system | `Ctrl+B` |

- The key opens and closes the sidebar:
	- `Cmd+B` or `Ctrl+B` on an open sidebar closes it, on a closed sidebar opens it.
- The open or closed state is kept across reloads.
